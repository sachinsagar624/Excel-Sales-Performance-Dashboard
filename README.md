# 📊 Sales Performance Dashboard | Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing sales performance using **Microsoft Excel**. An interactive Sales Performance Dashboard was developed using Pivot Tables, Pivot Charts, KPIs, and Slicers to identify sales trends, evaluate profitability, and compare category-wise and region-wise performance.

The dashboard helps transform raw sales data into meaningful business insights to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales revenue and profitability.
- Compare sales performance across product categories.
- Identify yearly sales trends and patterns.
- Evaluate region-wise revenue performance.
- Monitor key performance indicators (KPIs).
- Enable interactive analysis using Excel Slicers.

## 🛠️ Tools & Techniques

- **Microsoft Excel**
- Pivot Tables and Pivot Charts
- Excel Formulas and Aggregation Functions
- KPI Cards
- Interactive Slicers
- Data Analysis and Visualization

## 📂 Dataset Description

The project uses a sales transactions dataset containing order, customer, product, shipping, sales, and profitability information.

**Key columns include:**

- Order ID and Order Date
- Customer ID and Customer Name
- Category and Sub-Category
- Sales and Quantity
- Discount and Profit
- Shipping Cost
- Region, Market, and Country

The workbook also includes separate Returns and People sheets for supplementary analysis.

## 📈 Key Performance Indicators (KPIs)

The dashboard includes or is designed to support the following KPIs:

- **Total Revenue:** Overall sales generated.
- **Total Profit:** Total profit earned.
- **Profit Margin (%):** Profit as a percentage of sales.
- **Total Orders:** Number of unique orders.
- **Unique Customers:** Number of distinct customers.
- **Return Rate (%):** Percentage of orders that were returned.

## 📊 Dashboard Features

### 1. Sales by Category
Compares revenue across Furniture, Office Supplies, and Technology to identify top-performing categories.

### 2. Yearly Sales Trends
Visualizes annual sales performance to identify growth patterns and changes over time.

### 3. Region-wise Revenue
Compares sales across geographical regions to understand regional performance.

### 4. Interactive Slicers
Enables users to filter compatible Pivot Tables and charts by category, region, and other available fields.

### 5. Profitability Analysis
Uses total profit and sales to calculate profit margin and evaluate business performance.

## 💡 Key Insights

The initial category-wise analysis identified:

- **Technology** as the highest-revenue category.
- **Furniture** as the second-highest-revenue category.
- **Office Supplies** as the lowest-revenue category among the three.

The category-wise Pivot Table showed total sales of approximately **12.64 million** across the three categories.

*Note: Additional insights on yearly trends, regional performance, and profitability can be documented after completing the final dashboard analysis.*

## 🚀 How to Use

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Use the available Slicers to filter the analysis.
5. Explore category-wise sales, yearly trends, revenue, and profitability metrics.
